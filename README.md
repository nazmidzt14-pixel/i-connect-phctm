# i-connect-phctm

Prototaip klik (clickable prototype) untuk **i-Connect @ PHCTM** — sistem tempahan janji temu perpustakaan bagi Perpustakaan PHCTM, Universiti Kebangsaan Malaysia.

## Tentang projek ini

Sistem ini membolehkan pengguna menempah sesi konsultasi bersama pegawai perpustakaan mengikut servis yang disediakan:

- Perundingan Penerbitan
- e-Sumber@PTSL
- Kursus Kemahiran Maklumat

Prototaip ini dwibahasa (Bahasa Melayu / English) dan merangkumi keseluruhan aliran: log masuk, pemilihan servis & pegawai, pemilihan tarikh/masa, pengesahan tempahan, dan pengurusan janji temu (My Appointment).
